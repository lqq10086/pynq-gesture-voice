# 项目材料来源

团队自有代码采用 MIT 许可。手势和语音模型权重及其训练材料的来源和分发授权待核实，小镇图片素材由团队制作。第三方文件和生成产物保留各自来源和版权声明。

YOLO-FastestV2 上游源码及模型相关材料、AMD IP 与 Vitis 生成文件、OV5640 自动对焦固件等材料的适用分发条件还需核实。ALINX PS 配置脚本保留原文件中的版权和使用说明。

原先单独携带的音频工具、内核模块及裁剪源码归档已移除，语音运行改用系统组件；DCP 检查点不包含在公开候选包中；公开版会标明未核验 DCP，也可从匹配的原始工程恢复。详细目录和来源见项目根目录的 [第三方材料说明](../../third_party.md)。
