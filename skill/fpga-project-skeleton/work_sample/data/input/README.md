# data/input —— 输入样本

这里放「喂给系统的东西」，不放「系统产出的东西」。产出放 `data/golden/` 或 `build/`。

## 放什么

- 板端采集的原始帧、录制的音频、导出的原始张量。
- 上游给的测试图、视频片段、标定图。
- 复现某个问题所需的那一份最小输入（通常只有一张图或一个 bin）。

## 不放什么

- 生成物、缓存、日志（这些在 `build/` 与 `report/`）。
- 超过 50 MB 的整段数据集：放外部存储，这里只写一条 `source.md` 说明去哪取、怎么校验。
- 带个人信息的素材（人脸、录音里的姓名）。要放就先脱敏，并在 `source.md` 记录脱敏方式。

## 命名

`<来源>-<内容>-<尺寸或时长>.<扩展名>`，全小写、连字符分隔：

```
board-0044-open-palm-1280x720.png
mic-three-30s-16k.pcm
```

同名不同版本加 `-v2`，不要用「最终版」「新的」这类词。

## 管理

| 问题 | 做法 |
| --- | --- |
| 怎么知道这份输入对应哪次实验 | 实验记录里引用文件名与 sha256，不写「那张图」 |
| 换了一张输入，之前的结论还算不算 | 不算。数值一致性结论只对当时那张图成立，换输入要重跑 |
| 多大的文件可以进仓库 | 单文件 50 MB 以内；超过就外链，`source.md` 写下载地址与校验值 |
| 什么时候可以删 | 结论已被报告引用、报告里写了哈希之后 |

## 建议附带的信息

同目录 `source.md`，一行一份：

```
文件名 | 采集时间 | 采集条件（板卡/相机/光照/分辨率） | sha256 | 用于哪次实验
```

没有这条记录，三个月后没人能说清这张图是从哪来的。
