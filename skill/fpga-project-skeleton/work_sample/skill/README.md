# 本工程的技能包指针

正式技能包不在工程里重复维护，只在这里指向它。

| 需要做什么 | 去哪里看 |
| --- | --- |
| 给 agent 派任务、写任务书 | `fpga-task-prompts/prompts/` |
| 新建工程、写脚本与报告 | `fpga-project-skeleton/` |
| 用现成脚本查身份、查时序、查 DMA | `eda-script-runner/` |
| 遇到问题先查已知坑 | `fpga-pynq-pitfalls/` |

这四个目录与 `fpga-project-skeleton/` 同级，位于技能包根目录下。
工程自己的判断记录写在本项目的 `docs/decisions.docx` 里，不要写进技能包。
