# 分层排错

| 症状 | 第一个区分实验 | 后续判断与停止条件 |
|---|---|---|
| 连接失败 | 查当前串口/网络设备与实际控制台 | 设备消失先恢复供电/线缆/枚举，不继续加载 |
| import pynq 失败 | 查原启动脚本和 sys.executable | 选错环境先纠正，不默认覆盖系统 Python |
| bit/hwh 不配 | 离线检查并对照构建标识 | 不加载猜测组合 |
| IP/地址不符 | 仅解析当前 HWH 的 ip_dict | 查重命名/层次/旧文件，匹配前不访问 MMIO |
| 寄存器固定零 | 核对加载状态，再查时钟复位使能 | 按当前板 preset，不用全局复位或 ps7_init 试错 |
| 探针改变现象 | 查读取副作用 | 停用 FIFO/读清探针，不打印整个 register_map |
| 编号/极性错误 | 单路、单段、逐位核对 | 同版原理图、同拓展口与实际校准 |
| 丢事件/混合数据 | 分别记溢出、提交 ACK 和发送替换 | 区分事件队列、原子显示与快照合并 |
| DMA 卡住/数据旧 | 固定小输入，查通道状态与字节长度 | TLAST/缓存/地址/对齐，不无限等待或提前释放 |
| 越运行越慢 | 查采集、调度、队列和缓冲占用 | 最小复现，不无界排队或无限重试 |
| 报告对不上 | 对比构建 ID、哈希、测试主机和版本 | mock/仿真/实板分开，缺证据写 NOT_RUN |

一次只改变能区分假设的最小因素，确认后回归受影响接口与完整链路。保留失败原值；板端壁钟未校时另记客户端日期，不改历史时间。观察值、目标、估算和长期最坏值分开写。
